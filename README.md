# Programa-de-Digitalizaci-n-del-Archivo-Municipal-
El Programa de Digitalización del Archivo Municipal tiene como finalidad modernizar la administración documental del Ayuntamiento mediante un sistema informático que permita registrar, clasificar, consultar y administrar expedientes digitales. 

Con una arquitectura propuesta del sistema es una Arquitectura Cliente-Servidor en 3 Capas basada en un Modelo Relacional Centralizado con patrón de Herencia por Subclase.
